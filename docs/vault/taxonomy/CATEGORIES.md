# Vault category map (version 2026-10-01.1)

Generated by `tools/taxonomy/build_categories.py` from the OpenAlex topic taxonomy (snapshot 2026-10-01, CC0) and our arXiv, LCC and DDC crosswalks. Do not edit by hand; change the generator and rebuild.

## How categories work

- **Categories are metadata, never paths.** Text lives at `text/{h2}/{doc_id}.md` whatever its category, so reclassifying a document never changes an address.
- **Backbone:** OpenAlex's four-level taxonomy (domain, field, subfield, topic). OpenAlex assigns a primary topic to every paper it knows, so most papers are classified by the metadata lookup itself. The 4,516 topics are each mapped to one primary vault category and any number of secondary ones.
- **Every document has exactly one primary category and any number of secondary ones.** Filters and grep scopes match primary or secondary membership; coverage counts use the primary.
- **Cognitive-science overlay:** cognition-related topics outside psychology (philosophy of mind, psycholinguistics, cognitive AI, behavioural economics, psychiatry, animal cognition) are also members of psychology and cognitive science.
- **Study map:** psychology and cognitive-science topics also carry study areas (perception, memory, clinical, methods, and so on), so the tutor can scope a search the way a graduate curriculum is organised.
- **Books and preprints** reach the same map through crosswalks: LCC and DDC class numbers (from the book's own Cataloging-in-Publication block, or from metadata), and arXiv categories.
- **Precedence when sources disagree:** manifest_field, then openalex_primary_topic, then arxiv_primary_category, then lcc, then ddc, then inbox_folder_hint, then embedding_nearest_topic. Every assignment records its source and confidence; low-confidence ones are flagged in the intake report.
- **Unknowns are never dropped:** a document with no usable signal is classified by its nearest OpenAlex topic in embedding space (topic name, description and keywords), flagged as such.

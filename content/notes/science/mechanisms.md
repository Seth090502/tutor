# Science mechanisms (original notes, V1.0 seed)

Core idea: energy flows, matter cycles; genes encode proteins that run the flow.

- Method: hypothesis (falsifiable) -> controlled experiment -> baseline comparison.
- Cells: mitochondria make ATP; diffusion goes high->low passively; plants add wall + chloroplasts.
- Photosynthesis: 6CO2+6H2O+light->C6H12O6+6O2. O2 comes from H2O photolysis. Light reactions make ATP/NADPH (thylakoid); Calvin fixes CO2 (stroma) using them.
- Genetics: Aa x Aa -> 1/4 AA, 1/2 Aa, 1/4 aa genotypes; 3/4 dominant phenotype. Testcross AaBb x aabb -> 1/4 each combo.
- Newton: F=ma; action-reaction act on different bodies; energy: 1 kWh = 3.6 MJ.

Misconception guards: consensus != proof; O2 is not from CO2; kWh is energy not power.

# Math foundations (original notes, V1.0 seed)

Core idea: numbers obey laws; algebra is shorthand for those laws.

- Commutative: a+b=b+a, ab=ba. Associative: group freely. Distributive: a(b+c)=ab+ac.
- Fractions: a/b + c/d = (ad+bc)/bd. Percent = /100.
- Linear: ax+b=0 -> x=-b/a. Function f maps input->output; inverse undoes it.
- Quadratic: ax^2+bx+c=0 -> x=[-b+-sqrt(b^2-4ac)]/2a. Discriminant decides root count.
- Exponents: a^m*a^n=a^(m+n). Log is inverse: log10(1000)=3 because 10^3=1000.
- Geometry: triangle angles sum 180; Pythagoras a^2+b^2=c^2.

Worked micro-example: 2(x-3)=4x+2 -> 2x-6=4x+2 -> -8=2x -> x=-4. Check: LHS 2(-7)=-14, RHS -16+2=-14.

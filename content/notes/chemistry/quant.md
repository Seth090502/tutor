# Chemistry quantitative (original notes, V1.0 seed)

Core idea: atoms conserve; moles let us count by weighing.

- Atoms: atomic number = protons. Na (11p) -> Na+ has 10e. Group 1 loses 1e.
- Bonding: NaCl ionic (transfer); H2O bent polar covalent (share unequally); diamond vs graphite = same C, different lattice.
- Reactions: balance with coefficients, never subscripts. 2H2+O2->2H2O. Types: synthesis, double displacement (AgNO3+NaCl), combustion (CH4+2O2->CO2+2H2O).
- Stoichiometry: grams->moles (÷M) -> ratio -> moles -> grams. 36 g H2O /18 = 2 mol. Limiting reactant runs out first.
- Acids: pH=-log[H+]; pH 3 is 100x stronger than pH 5 (log scale). Neutralization -> salt + water.

Drill: [H+]=1e-4 -> pH 4. Avogadro 6.022e23 per mole.
